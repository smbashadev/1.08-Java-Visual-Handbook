# Object-Oriented Programming (OOP)

## Overview

Welcome to the **Object-Oriented Programming (OOP)** section of the **Java Visual Handbook**.

This folder contains a comprehensive collection of professionally designed infographic images covering the fundamental and advanced concepts of Object-Oriented Programming in Java. The topics are organized in a logical learning sequence, beginning with the introduction to OOP and progressing through classes, objects, constructors, inheritance, polymorphism, abstraction, interfaces, packages, and object relationships.

These infographics are designed to simplify OOP concepts through visual explanations, making them valuable for learning, revision, interview preparation, and real-world software development.

---

## Learning Objectives

After completing this section, you will be able to:

- Understand the fundamentals of Object-Oriented Programming.
- Learn how classes and objects work in Java.
- Understand object creation and constructors.
- Master constructor overloading and constructor chaining.
- Learn the purpose of the `this` and `super` keywords.
- Understand Encapsulation, Inheritance, Polymorphism, and Abstraction.
- Learn Interfaces, Abstract Classes, and Packages.
- Understand Association, Aggregation, and Composition.
- Differentiate between Compile-Time and Runtime Polymorphism.
