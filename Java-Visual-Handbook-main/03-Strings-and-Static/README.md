# Strings and Static

## Overview

Welcome to the **Strings and Static** section of the **Java Visual Handbook**.

This folder contains a professionally designed collection of infographic images covering two essential Java concepts: **String Handling** and the **`static` keyword**. These topics are fundamental to Java programming and are frequently used in real-world applications as well as technical interviews.

The infographics are organized in a structured learning sequence, beginning with String fundamentals and progressing through String Pool, immutability, String comparison, common String methods, and the various uses of the `static` keyword.

---

## Learning Objectives

After completing this section, you will be able to:

- Understand the concept of Strings in Java.
- Learn how the `intern()` method works.
- Explore the Java String Pool.
- Understand String immutability and its advantages.
- Differentiate between String, StringBuffer, and StringBuilder.
- Learn commonly used String methods.
- Understand the difference between `==` and `equals()`.
- Learn the purpose and usage of the `static` keyword.
- Understand static variables, methods, and blocks.
- Learn why the `main()` method is declared as `static`.
- Explore the valid syntaxes of the `main()` method.
