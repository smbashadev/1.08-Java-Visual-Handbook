# Exception Handling

## Overview

Welcome to the **Exception Handling** section of the **Java Visual Handbook**.

This folder contains a professionally designed collection of infographic images covering the fundamental and advanced concepts of Exception Handling in Java. Exception Handling is one of the most important features of Java, enabling developers to write robust, reliable, and maintainable applications by handling runtime anomalies gracefully.

The infographics are organized in a structured learning sequence, beginning with the introduction to Exception Handling and progressing through exception types, exception hierarchy, checked and unchecked exceptions, exception handling mechanisms, keywords, and custom exceptions.

---

## Learning Objectives

After completing this section, you will be able to:

- Understand the fundamentals of Exception Handling in Java.
- Differentiate between Exceptions and Errors.
- Learn how Runtime Exception Handler and Default Exception Handler work.
- Understand exception propagation in a multiple method hierarchy.
- Identify different types of exceptions.
- Explore the Java Exception Hierarchy.
- Understand method overloading rules with respect to exceptions.
- Differentiate between Checked and Unchecked Exceptions.
- Learn the differences between `final`, `finally`, and `finalize()`.
- Master the usage of `try-catch`, `finally`, `throw`, and `throws`.
- Learn how to create and use Custom Exceptions.
